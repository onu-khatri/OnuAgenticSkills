# Developer documentation

This section explains how to select the workshop agents and skills, how they fit together, and where developer input is required.

- [Agents](agents.md) — responsibilities and selection guidance.
- [Skills](skills.md) — skill catalog grouped by outcome.
- [Workflow and human gates](workflow-human-gates.md) — lifecycle, approvals, story/issue statuses, and delivery boundaries.

These guides describe the installed capabilities; `AGENTS.md` and each skill's `SKILL.md` remain authoritative. Do not change an agent or skill definition as part of using these guides.
